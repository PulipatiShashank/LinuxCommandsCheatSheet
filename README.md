# 🐧 Linux Commands Cheat Sheet

This repository contains a **PDF cheat sheet** of commonly used Linux commands, organized by category for quick reference.

## 📄 What's Inside

The cheat sheet includes commands for:

- 📁 File and Directory Management  
- 🔍 File Search and Viewing  
- 👤 User Management  
- 🔐 Permissions and Ownership  
- 📦 Package Management (Debian/Ubuntu & RedHat/CentOS)    
- 🧠 System Information  
- 🌐 Networking  
- 📂 Archives and Compression   
- 🧼 System Cleanup  


## ✅ Perfect For

- Linux beginners and intermediate users  
- System administrators  
- Developers working in Unix/Linux environments  
- Students preparing for Linux-related exams
